# Program Street Madani

## 1) Ringkasan Program

- **Nama program**: Street Madani
- **Tujuan**: Mengaktifkan ruang komuniti setempat melalui intervensi belia, ekonomi mikro, mobiliti komuniti, dan advokasi kos hidup.
- **Kawasan fokus awal**: Tapah, Hutan Melintang, Perak.
- **Tempoh awal**: 12 bulan (pilot + scale-up).

## 2) Objektif Utama

1. Menurunkan tekanan kos hidup komuniti berpendapatan rendah.
2. Menambah akses program belia/komuniti berkualiti.
3. Meningkatkan penyelesaian aduan setempat secara berstruktur.
4. Memperluas sokongan mobiliti komuniti (contoh transit anak).

## 3) Komponen Intervensi

### A. Kos Hidup
- Klinik harga barang asas (pemantauan + intervensi komuniti).
- Kerjasama vendor komuniti untuk bakul harga mampu milik.

### B. Belia & Komuniti
- Aktiviti hujung minggu: sukan, kemahiran digital, sukarelawan.
- Mikro-grant untuk inisiatif belia setempat.

### C. Aduan & Penyelesaian
- Saluran aduan satu pintu + SLA respons.
- Sesi townhall mini bulanan untuk semak status isu.

### D. Mobiliti Transit Anak
- Pemetaan keperluan transit sekolah/aktiviti.
- Pilot transit komuniti berjadual.

## 4) KPI Program

| KPI | Baseline | Target 6 Bulan | Target 12 Bulan |
|---|---:|---:|---:|
| Penyertaan program belia (orang) | 0 | 300 | 800 |
| Aduan selesai ikut SLA (%) | 0 | 70% | 85% |
| Rumah tangga menerima manfaat kos hidup | 0 | 200 | 500 |
| Laluan transit komuniti aktif | 0 | 2 | 5 |

## 5) Milestone

- **M1 (Bulan 1-2)**: setup pasukan, baseline data, engagement komuniti.
- **M2 (Bulan 3-4)**: pelaksanaan pilot kos hidup + belia.
- **M3 (Bulan 5-6)**: launch saluran aduan + transit pilot.
- **M4 (Bulan 7-9)**: optimasi model dan perluasan lokaliti.
- **M5 (Bulan 10-12)**: evaluasi impak + blueprint scale-up.

## 6) Struktur Owner

- **Program Lead**: keseluruhan eksekusi Street Madani.
- **Community Lead**: engagement lokaliti & aktiviti belia.
- **Policy/Ops Lead**: SOP aduan, SLA, dan koordinasi rentas agensi.
- **Data Lead**: dashboard KPI dan evaluasi impak.

## 7) Risiko Utama & Mitigasi

- **Partisipasi rendah** → aktivasi rakan komuniti & outreach mikro-zon.
- **Data tidak konsisten** → standardkan format input dan review mingguan.
- **Sumber terhad** → fasa prioriti + kolaborasi NGO/CSR tempatan.
- **Koordinasi lintas pihak lambat** → war-room cadence mingguan + PIC jelas.
