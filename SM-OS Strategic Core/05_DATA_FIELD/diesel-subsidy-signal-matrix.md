# Diesel Subsidy Signal Matrix

## Tujuan
Menyediakan indikator amaran awal (early warning) untuk memantau impak rasionalisasi subsidi diesel.

## Isyarat Utama Mingguan

| Dimensi | Indikator | Sumber | Ambang Amaran |
|---|---|---|---|
| Harga | Perubahan harga barang asas (%) | Survei pasar setempat | > +3% / minggu |
| Logistik | Kos penghantaran PMKS (%) | Persatuan logistik / PMKS | > +5% / minggu |
| Sosial | Bilangan aduan kos hidup | Hotline/portal aduan | > +20% / minggu |
| Pendidikan | Kes transit pelajar terganggu | Sekolah/PBT | > 50 kes / minggu |
| Sentimen | Sentimen awam negatif (manual coding) | Media sosial + townhall | Trend negatif 2 minggu berturut |

## Tindakan Ikut Status

- **Hijau**: terus pemantauan rutin.
- **Kuning**: aktifkan semakan mingguan + intervensi mikro.
- **Merah**: aktifkan war room harian + pakej mitigasi segera.
