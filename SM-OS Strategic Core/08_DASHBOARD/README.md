# 08_DASHBOARD

## Boilerplate
- `kpi-summary.md` — ringkasan KPI mingguan/bulanan.
- `okr-status.md` — status objective & key results.
- `risk-monitor.md` — risiko teratas dan mitigasi.
- `health-check.md` — indikator kesehatan sistem.

- `weekly-dashboard-template.md` — template strategic briefing dashboard (PMO/War Room) dengan format slide + insight ringkas setiap chart.
