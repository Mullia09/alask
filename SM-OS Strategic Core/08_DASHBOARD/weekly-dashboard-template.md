## Definition of Done (Strategic Briefing Deck)

Checklist sebelum presentasi:
- [ ] Setiap slide mempunyai **insight ringkas** di bawah chart/table.
- [ ] Executive summary memuat keputusan yang diminta dari leadership.
- [ ] Program Progress Chart menunjukkan planned vs actual + variance.
- [ ] Issue Heat Chart dikemas kini dengan skor terkini.
- [ ] Sentiment Chart memaparkan trend sekurang-kurangnya 4 minggu.
- [ ] Semua blocker kritikal memiliki owner + SLA penyelesaian.
