# SM-OS Strategic Core

Struktur ini berfungsi sebagai kerangka kerja strategis untuk perencanaan, eksekusi, analisis, dan pelaporan.

## Struktur Folder

- `01_IDENTITY/` — visi, misi, positioning, prinsip merek, dan persona inti.
- `02_DOCTRINE/` — aturan main, kebijakan operasional, SOP strategis, dan guardrails.
- `03_PROGRAMS/` — peta inisiatif, roadmap program, milestone, serta owner.
- `04_WAR_ROOM/` — command center untuk prioritas mingguan, issue kritis, dan keputusan cepat.
- `05_DATA_FIELD/` — sumber data, kamus metrik, eksperimen, insight, dan evaluasi.
- `06_TEMPLATES/` — format dokumen standar agar eksekusi konsisten.
- `07_OUTPUTS/` — artefak final: deck, report, brief, playbook, dan deliverables.
- `08_DASHBOARD/` — ringkasan KPI, status objective, dan health check sistem.

## Alur Kerja Singkat

1. Definisikan arah di `01_IDENTITY` dan `02_DOCTRINE`.
2. Turunkan ke inisiatif di `03_PROGRAMS`.
3. Pantau ritme eksekusi harian/mingguan di `04_WAR_ROOM`.
4. Validasi dengan data di `05_DATA_FIELD`.
5. Gunakan format baku dari `06_TEMPLATES`.
6. Publikasikan hasil ke `07_OUTPUTS` dan status ke `08_DASHBOARD`.
